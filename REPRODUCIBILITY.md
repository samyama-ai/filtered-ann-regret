# Reproducibility

## Environment
- Python ≥ 3.10. Deps: `numpy scipy faiss-cpu hnswlib matplotlib` (+ `pytest`). Install: `pip install -e .`
- Determinism: all randomness is seeded (vectors, labels, long-range graph edges, bootstrap). The only
  non-determinism is faiss/BLAS thread scheduling, which does not affect the reported statistics.
- Hardware used: the n=10⁷ sweep ran on a 16-vCPU / 30 GB AWS c5.4xlarge spot instance (ap-south-1);
  everything else (n ≤ 10⁶, SIFT1M, percolation) runs on a laptop in seconds–minutes.

## One-command reproductions
```bash
pip install -e . && python -m pytest -q          # 30+ tests: closed forms, H0 gate, percolation
python bench/run_h2_synthetic.py                  # H2 criticality + figure (single n, seconds)
python bench/run_real.py                          # H2 at n in {1e5,1e6,1e7} + H3 collapse + SIFT anchor
python bench/run_percolation.py                   # H1b: in-filter percolation s_c scaling
bash   bench/fetch_data.sh                         # (optional) download SIFT1M real-geometry anchor
```
Override the n-sweep to skip the heavy point: `FANN_NS=100000,1000000 python bench/run_real.py`.

## Data provenance
- **Synthetic** (default): clustered-Gaussian vectors, fully generated from seeds — no download.
- **SIFT1M** (real-geometry anchor): ANN_SIFT1M (Jégou et al., IRISA/TEXMEX), 1M×128 base + 10k queries,
  fetched by `bench/fetch_data.sh`. Not vendored.

## What each number comes from
Every figure/table is regenerated by the scripts above into `results/*.npz|json` and `figures/*.png`.
Pre-registration (frozen hypotheses + decision rules, with a dated pre-data amendment) lives in
`PREREGISTRATION.md`. Claims in the paper/README equal the frozen decision-rule outcomes.
